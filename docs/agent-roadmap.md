# Agent ideas for Voxraft

**Current state:** Voxraft has a command planner, a rule-based Design insight, an Architecture Review Agent, a Layout Critic Agent, and a Visual Design Agent. The agents inspect the current scene and propose changes for user acceptance. Voice support is English-only (`en-IN`). Other agents below are planned.

| Priority | Agent | Trigger and useful behavior | Tools it would choose from | Output |
| --- | --- | --- | --- | --- |
| 1 | **Architecture Review Agent — implemented** | On “review this diagram” or a button click, inspect the graph for a shared database dependency or an isolated component. | Find shared dependencies; find isolated components; trace a node's connections. | One evidence-backed finding with affected elements, **Highlight**, and an optional **Add replica** proposal. |
| 2 | **Command Recovery Agent** | When a spoken command cannot be resolved, investigate what the user probably meant using the transcript, selected element, and recent edits. | Search matching nodes; inspect recent commands; dry-run candidate actions. | A short choice such as “Did you mean the main or backup database?” without changing the scene. |
| 3 | **Layout Critic Agent — implemented** | On “make this easier to read” or a button click, compare the current layout with layered and grid arrangements. | Group connected blocks, keep isolated blocks aside, and measure overlaps, blocked connections, straight-line crossings, backward edges, connection length, and spread. | A routed-arrow SVG preview and score comparison that the user can apply or discard as one undoable edit. |
| 4 | **Visual Design Agent — implemented** | On “style this diagram” or a button click, inspect component roles, named groups, and connection targets. | Inspect roles and groups; inspect connections; choose a role or group emphasis. | A color and typography preview for nodes, arrows, and connection labels. Apply or discard it as one undoable edit. Default styling remains neutral. |
| 5 | **Architecture Explainer Agent** | On “explain this system,” trace the diagram and identify what each connection actually shows. | Read labels, groups, edges, and selected elements; follow paths. | A concise spoken or written walkthrough grounded in the diagram, with uncertain assumptions called out. |
| 6 | **Design Interview Agent** | Ask the user why a component or dependency exists, listen to the answer, and use it to refine a review. | Inspect the graph; ask one question; retain the answer for the current review. | A better-grounded design suggestion or a clear explanation of the tradeoff. |

The Architecture Review Agent's clearest demo is three services connecting to one database: it inspects those dependencies, explains the potential risk, and offers to add a replica. For the Layout Critic Agent, deliberately overlap two blocks, click **Critique**, inspect the preview, then apply and undo it. With a configured AI model, the critic calls a measurement tool and selects a candidate; without one, measured rules choose the lowest-scoring candidate. The Command Recovery Agent is next because it improves live voice reliability.

The agents have bounded runs, return evidence tied to stable element IDs, and cannot edit the canvas directly. The user accepts a proposal through the existing undo system. If the scene changes during an agent run, the stale proposal is discarded. Credentials and agent orchestration stay on the FastAPI backend. Apply the same limits to future agents.

Planned Visual Design extension: [meaningful shapes](semantic-shapes.md). Complete native ellipse/diamond previews, labels, and arrow geometry first; then propose shapes with reasons and user acceptance. Add composite database cylinders before actors, queues, and clouds. This extends the existing agent rather than adding a separate shape agent.
